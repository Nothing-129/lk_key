# 首页布局 · 第二轮

打开 `index.html` 查看三个布局，顶部可切换单版。

- 01 底部操作台：车辆展示区 + 集中的主次操作。
- 02 侧边工具栏：右侧辅助操作 + 底部独立开关锁。
- 03 分层抽屉：悬浮开关锁 + 可收起的辅助操作抽屉。

按反馈，车辆区域留空，未放车图、未实现或接入 3D；三版共用原 App 的 dusk_scene.png 暮色场景，采用深灰面板和灰底白字按钮。NFC 仅在右上角更多设置内可见。按钮为模拟交互，不发送车辆指令。

从仓库根目录运行 `python3 -m http.server 5188`，访问 http://localhost:5188/designs/2026-10-13-layouts-v2/ 。也可直接打开 HTML，保持 assets 相对路径即可。
