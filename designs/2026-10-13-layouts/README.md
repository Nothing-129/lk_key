# 首页布局 HTML 预览

打开 `index.html` 即可本地预览，无需安装依赖。图片位于相邻的 `assets/`，请保持目录结构。

- A 留白极简：车辆居中、双主按钮、四项横排控制。
- B 掌控驾驶舱：圆形开锁主键、双列次级操作。
- C 入夜暮色：完整场景、下方悬浮操作面板。
- D 日常卡片：紧凑车辆卡、上移主要操作、模块化功能。

顶部切换并排比较或单版展示，单版支持手机宽度。按钮提供模拟指令反馈，开关锁会同步更新本地记录与 NFC 下次动作；洗车打开展示弹层；NFC 收入“更多设置”，首页不再显示独立卡片或下次贴片动作。不连接蓝牙，不发送实际指令。使用既有领克车图与暮色场景，未接入 3D 模型。

临时预览服务（仓库根目录）：

```sh
python3 -m http.server 5188
```

访问 http://localhost:5188/designs/2026-10-13-layouts/ 。
