# LYNK & CO 03 · H5 3D 数字车钥匙

独立 Three.js 效果页，不连接车辆、蓝牙或原 Android 程序。

另有 `android.html` 作为原生钥匙 App 的内嵌展示入口：复用同一模型与渲染代码，仅接受原生端确认后的动画状态。独立演示页继续使用自己的演示按钮。

## 运行

```sh
cd h5-car-key
npm install
npm run dev
```

打开 http://localhost:5178 。手机在同一局域网可使用开发服务器输出的 Network 地址。

## 当前效果

使用用户提供的 `lynk03.rar` 中的真实领克 03 车身模型，车漆对照 APP 的 `car_render.png` 调为低饱和钢灰色，使用中性柔光和长条反射，并校正深色车窗、天窗及前部饰件。

- 拖动可连续旋转、俯仰；双指、滚轮、键盘加减键缩放。
- 前侧、侧面、车尾快捷视角；重置按钮和 `Home` 恢复默认视角。
- 锁车时左右后视镜折叠，解锁时展开；默认锁车状态下后视镜收起。
- 开关锁时，左右前日行灯同时短亮琥珀黄色约 0.7 秒，模拟兼作转向灯的确认效果，随后恢复白色日行灯。原生 App 仅在收到设备确认后触发。
- 四扇车窗逐渐降入车门或升起，玻璃在窗沿处裁切。
- 后备箱盖、内侧结构与附件沿铰链翻转；开启时自动转向车尾。
- 开合动作可随时反向，后视镜、车窗和后备箱可同时运动。
- 开关锁尾灯按用户视频近似还原：每侧七组成对灯片；暂将前段映射为开锁，两轮由内向外点亮并停留，约 3.2 秒；后段映射为关锁，全亮后由外向内收灭，下方灯带最后熄灭，约 2.45 秒。结束后回到熄灭状态。
- 寻车单独展示地面光圈和灯光闪烁；开关锁不展示光圈。
- 地址加 `?view=rear` 可直接从车尾视角检查灯效。
- 尾灯未点亮时显示银白色成对斜竖灯片、透明光学件和下部红色回折边框，黑色灯腔内保留银色反光件；内侧灯组随后备箱盖转动，外侧灯组固定在车身。流水动画只控制发光，不再把熄灭灯片染黑。
- 后备箱“领克”“03”及中央 LYNK & CO 使用独立亮银色金属材质，中间饰板为亮黑色；去掉源模型叠放的 03+、PHEV、CYAN 备用尾标。
- 前脸换用实拍对应的原厂保险杠，保留同色侧盖和黑色进气口；移除圆形雾灯与改装翼片。前灯分为透明罩壳、黑色灯腔、反光杯、矩形光学模块和双条日行灯。
- 尊重系统“减少动态效果”设置，此时部件直接切换到目标状态。

这些控制仅为页面演示，不会控制真实车辆。

## 素材处理

原始包包含 Blender 2.92 文件和 FBX，共 506 个网格，带多个散开的外观套件。保留居中的主车身，设置左右后视镜转轴、后备箱铰链和四扇独立玻璃。静态网格、后视镜和后备箱网格分别按材质合并，GLB 使用 Draco 压缩，约 1.4 MB。

素材包没有贴图，也没有车轮。页面重建了灰色漆面、玻璃、灯罩和内饰的 PBR 材质；轮胎与轮毂按模型轮拱位置及 2.73 米轴距补建。轮毂按用户提供的侧面实拍重建为五组 Y 形分叉、窄银色切削面及黑色内层，带五孔螺栓、中心标识、内凹刹车盘和卡钳。车轮横向中心距车身中线 0.800 米，轮毂总成内收 0.038 米，银色外沿位于轮胎侧壁内，避免正后方出现突出的亮边。

车尾下护板恢复为深色材质；移除多余管件（1416、1433），修剪底盘单排气总成（1450）伸出左侧保险杠的末端，保留其隐藏的底盘部分。用等尺寸、等高度的空心双排气管口替换原管口（5350、5359）。

前杠采用原始场景左侧的原厂套件（4588、4600、4612），沿 X 轴平移 2.689 米装配；替换居中的雾灯款前杠及其饰件。保留原有中网、主灯和日行灯网格，单独配置灯罩与灯腔材质，并补充每侧四个矩形光学模块。

移除右前翼子板上与实拍不符的黑色风口饰件及内芯（5408、5417），露出原本完整的灰色翼子板；左右翼子板本体（3214、3232）均保留。

所有模型、解码器和字体均本地加载，无运行时 CDN 依赖。

## 文件

- `src/exterior.js`：真实模型加载、光照、环视、后视镜折叠、车窗裁切和后备箱铰链。
- `src/drl-signal.js`：前日行灯的黄色确认信号及白色恢复，独立于尾灯流水时序。
- `src/tail-lights.js`：识别模型灯片、成对分段与共享着色器亮度控制，灯片随后备箱移动。
- `src/tail-light-sequence.js`：独立的开关锁时序；`node scripts/test-tail-lights.mjs` 验证流水方向、轮次及熄灭终态。
- `src/part-motion.js`：可反向、互不干扰的部件动画。
- `src/wheels.js`：按参考照片重建的黑银五组 Y 形轮毂、轮胎和制动盘。
- `src/vehicle-finish.json`：模型导出和 Three.js 共用的车漆、玻璃与饰件色板，颜色值采用线性 RGB。
- `src/main.js`：车钥匙交互和状态反馈。
- `src/style.css`、`index.html`：手机和桌面布局。
- `public/vehicle/lynk03.glb`、`model.json`：处理后的模型与素材说明。
- `public/draco/`：本地 Draco 解码器及许可。
- `scripts/prepare-model.py`：可重复运行的 Blender 模型整理与导出脚本。
- `.qa/model-source/`、`.qa/lynk03.rar`：原始文件，已被 git 忽略。

重新导出：

```sh
blender --background --disable-autoexec .qa/model-source/lynk03/lynk03.quads.blend --python scripts/prepare-model.py
```

之前的懂车帝灰色外观图保留在 `.qa/exterior-reference/`，作为外观对照，当前页面使用 GLB。

## 构建

`npm run build` 生成 `dist/`。`npm run preview` 预览构建产物。

`npm run build:android` 将专用展示入口、模型、解码器和许可打包到 `../app/assets/vehicle3d/`，由根目录 `build.sh` 自动调用。Android 将 HTTPS 资源请求映射到这些本地 assets，模型展示无需网络。修改模型后重新构建 APK 即可更新 App。
