# 蓝牙钥匙 Android App

针对已配对的 `LYNK_CO_03`，提供“开”“关”两个按钮。协议来自本机小程序 `wx1a1d99a3cd890b65` 的静态分析。

- Android 12 及以上；需要附近设备权限。
- 服务 FFE0，写入 FFE2，通知 FFE1。
- 点击“开”：普通开锁，命令 0x02，无业务参数。
- 点击“关”：关锁升窗，命令 0x01，业务参数 `01 88 13`，执行一次持续 5000 毫秒的长按；完整帧为 37 字节。
- 所有命令包含时间和 MD5。
- 先同步时间并检查设备授权；只有设备报告已授权才启用按钮。
- 不导出微信凭证，不执行配对重置；不申请网络权限。
- 收到成功回包仅代表设备确认命令，实际车辆状态须现场确认。

## 构建

当前机器使用 Android SDK 35、Build Tools 35.0.0 和 Homebrew OpenJDK 17：

```sh
./build.sh
adb install --no-incremental -r build/lk-key.apk
```

源码位于 `app/src/com/zcy/lkkey`。APK 为本地调试签名版本。

## 1.5 版：更多车辆控制

首页保留“开”和“关”，下滑提供开窗、关窗、后备箱和洗车入口。用户明确要求：首页和小部件“关”继续关锁并升窗。

指令对照原小程序 `pages/index/index.js`、`pages/carwash/carwash.js` 和 `common/vendor.js`：

| 功能 | opcode | 业务参数 |
| --- | --- | --- |
| 开窗 | 2 | `01 88 13`，一次 5000 毫秒长按开锁 |
| 关窗 | 1 | `01 88 13`，一次 5000 毫秒长按关锁 |
| 后备箱 | 3 | 空 |
| 读取洗车模式 | 10 | 空 |
| 设置洗车模式 | 10 | 开始时间 7 字节 + 结束时间 7 字节 + 当前运行标志 1 字节 + 重连自动退出 1 字节 |
| 停止洗车模式 | 10 | 开始/结束时间与运行标志清零，保留自动退出选项 |

洗车回复按原小程序解析 16 字节状态；面板支持读取、日期时间选择、停止及蓝牙重连后自动退出开关。必须成功读取设备状态后才允许修改；成功后显示设备返回的状态。原程序提示洗车模式会解锁整车、暂停离车自动锁车，面板保留该说明。开始和结束时间由设备执行，App 没有本地定时后台任务。

最长洗车设置帧为 50 字节，GATT 仍请求 MTU 64，最低要求升为 53（含 ATT 头）。

验证：构建与签名校验通过；`ProtocolTest`、`WashModeTest` 校验开关窗/后备箱/洗车封包、预约与运行标志、停止清零、回复解析与非法回复；Android 14 模拟器检查四个辅助按钮在离线时禁用、洗车面板渲染和桌面小部件离线流程。实车新功能尚未测试。
